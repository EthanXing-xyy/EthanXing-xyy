**Embodied AI and robot learning**

| Project | What it does |
|---|---|
| [ImplicitRDP-ForceLoop](https://github.com/EthanXing-xyy/ImplicitRDP-ForceLoop) | Does tactile *prediction* help a visuo-tactile diffusion policy?
